HAPPY BIRTHDAY SHAMAL — FROM RAHUL

NEW VERSION FEATURES
- Five pages: Home, Memories, Love Quiz, Letter and Surprise.
- Four included memory photos. Tap any photo to open it large; tap outside or X to close.
- Original instrumental birthday melody included as assets/birthday-melody.wav. Tap the music button to play/pause.
- Seven love quiz questions: the two requested February questions are first, followed by the existing quiz questions.
- Responsive layout for mobile phones, tablets and desktop.

HOW TO USE
1. Extract the ZIP file.
2. Open shamal_birthday_website/index.html in a browser to preview.
3. To publish with GitHub Pages, upload the CONTENTS of this folder to your repository (keep the assets folder).
4. Keep all HTML, CSS, JS and assets together; do not move the images or music out of assets.

Music playback begins only after the visitor taps the music button, as required by modern browsers.
